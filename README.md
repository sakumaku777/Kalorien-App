# Teller – Kalorien per Foto

Eigene Web-App (PWA): Essen fotografieren, KI schätzt Kalorien und Makros.

- Fotoanalyse über die Gemini-API (Gratis-Kontingent, eigener Schlüssel) oder per Kopieren-Einfügen mit der Gratis-App von ChatGPT/Claude
- Alle Daten bleiben lokal auf dem Gerät (localStorage)
- Auf dem iPhone: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“
